# Karty montażowe Margot Decor (instrukcja składania do kartonów)

Stały wzór (A4 poziomo, tylko PL), ustalony z Arkadiuszem 2026-11-04:
- nagłówek: logo, "Karta montażowa · instrukcja składania", nazwa lampy + rozmiar, model fabryczny, wymiary
- schemat montażu (widok z boku) z oznaczeniami kryształów A/B w każdym rzędzie
- przekrój obręczy (powiększenie) + rozmieszczenie kryształów po rzędach
- dane techniczne: nazwa, wymiary, zasilanie, źródło światła, zawieszenie
- kryształy w zestawie: poz., opis, ilość, masa
- kolejność montażu + pielęgnacja

Fonty i logo z ../karta-katalogowa (bez zmian w tamtym szablonie).
Render: `node render.js <lampa>/<plik>.html <plik>.pdf <plik>.png`
Uwaga: fabryczne karty mają błędy, zawsze wg poprawek Arkadiusza (Olivia: rzędy A, A, B; fabryka miała AB, A, C).
